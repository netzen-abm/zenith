# ZENITH — Data Artifact Compendium

This file consolidates the previously created architecture, ontology, federation, UX, authorization and gate-register spreadsheet material into a repository-readable archival reference. The original workbook structures are represented by source headings and tables. This is not an automatic claim that every historical row is still canonical; reviewed ZENITH contracts and ADRs control implementation.

- Implementation Contract Freeze Register
- Ontology and Federation Matrix
- Canonical Data Model

- Security, Federation and Figma IA
- Application IA / Route / Surface Map
- Endpoint / Resource / Authorization Matrix
- Representative Journey Gate Register
- ZENITH Architecture Governance and Name Due Diligence
- ZENITH Application Implementation Gate Register

## Canonical interpretation rule
Historical workbook rows are retained for traceability. If a row conflicts with a later approved ZENITH governance document, contract, migration or ADR, the later approved artifact wins and the conflict should be recorded rather than silently hidden.
