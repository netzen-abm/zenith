# AI Capability Boundary

AI is an optional capability layer, not the system of record.

AI components must:

- receive only minimum necessary authorized context;
- preserve source, evidence, provenance, and epistemic status;
- distinguish documented fact, observation, derivation, interpretation, hypothesis, tradition/oral knowledge, contested claims, and unknowns;
- support replacement of models/providers through an adapter boundary;
- never expose sensitive heritage information merely because it exists in Core;
- make generated inference identifiable as generated inference.
